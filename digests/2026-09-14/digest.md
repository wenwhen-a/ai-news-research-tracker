## Does Video Memory Use What It Retrieves? A Causal Audit of Memory Specificity
- **arXiv:** 2609.12090 · https://arxiv.org/abs/2609.12090
- **Submitted:** 2026-09-10
- **Authors:** Aditi Tiwari, Akshit Bhalla, Darshan Prasad, Heng Ji
- **Qualifying affiliation(s):** Adobe Research — Akshit Bhalla, Darshan Prasad (Aditi Tiwari: work done during an internship at Adobe Research; primary university affiliation University of Illinois Urbana-Champaign)
- **Categories:** cs.CV
- **Open release:** none found
- **Shipped counterpart:** none found

**Summary (≤3 sentences):** The paper introduces "read-time memory substitution," a causal-audit method that swaps out the memory content a video model retrieves at inference time while leaving the rest of its computation unchanged, in order to separate whether a model's memory helps at all from whether the specific retrieved content is what actually drives that benefit. The authors apply this to frozen video world models (DINO-WM, V-JEPA 2, WorldMem) and to SAM 2's memory-based video segmentation.
**Purpose (≤3 sentences):** Standard memory ablations (removing memory entirely) can show that memory helps, but cannot show whether the gain depends on retrieving the correct past content versus just having some generic memory representation present. The authors aim to directly test that distinction ("memory benefit" vs. "memory specificity") across different memory-based video systems.
**Breakthrough (≤3 sentences):** The authors report that on frozen video world models, identity-free control memories (containing no evaluation-specific content) recover "essentially the full benefit" on the Ego-Exo4D and 7-Scenes benchmarks and about 70% on TUM, and that in an Ego-Exo4D dose-response test, recovery falls from 102% to 1% as substituted memory values move away from observed training-memory representations — evidence the authors interpret as "representation repair" rather than true content-specific recall for those models. By contrast, they report WorldMem and SAM 2 show much stronger content dependence: a wrong memory from the same trajectory recovers 94.1% of WorldMem's PSNR benefit versus 43.7% from a disjoint trajectory/biome, and on SAM 2's DAVIS evaluation, substituting a valid-but-wrong spatial memory drops the mean region/boundary score from 0.926 to 0.182 (falling to 0.000 on MOSEv2 reappearance cases).
**Tools & method (≤3 sentences):** Method: "read-time memory substitution" — replacing the memory value a model consumes at a given read step without altering surrounding computation — applied across a "substitution ladder," dose-response tests, and a leakage-safe TUM split. Models/datasets: DINO-WM and V-JEPA 2 (frozen video world models), WorldMem (native generative memory system), and SAM 2 (video segmentation) evaluated on Ego-Exo4D, 7-Scenes, TUM, DAVIS, and MOSEv2.
**Limitation (≤3 sentences):** The authors state their conclusions are bounded by the specific models/interventions studied: the full substitution-ladder and dose-response analysis is only run on DINO-WM, V-JEPA 2 only gets a correct-vs-wrong check, and WorldMem does not get the same representation-repair analysis since it does not support directly removing its memory interface (so its recovery is measured relative to zero content, not a true memory-off condition). They also note the leakage-safe TUM split has only two evaluation takes (suggestive, not precise), SAM 2 provides only one native-memory example and "should not be taken as representative," and because model families use different tasks/metrics, the paper compares patterns of content dependence rather than a single common numerical ranking across systems.
