## Roblox Studio — Texture Generation Tools (Quality Mode update)
- **Company:** Roblox
- **Status:** Public beta/preview (Studio Beta/Assistant) · **Released:** 2026-10-16 · **Update**
- **Surface:** Studio tool (Assistant-driven texture generation for 3D meshes)
- **Primary source:** https://devforum.roblox.com/t/beta-introducing-quality-mode-for-texture-generation/4938282
- **Underlying research:** no traceable paper
- **Availability:** Opt-in Studio Beta / Assistant feature, free to Roblox creators; accessed via Model > Texture menu, right-click Generate > Texture, or the `/generate_texture` Assistant command.

**What shipped (≤3 sentences):** Update since 2026-09-23: Roblox added a "Quality" mode to its in-Studio AI texture generation tool (first shipped as the Fast-only "Texture Generation Tools" beta), alongside the existing "Fast" option. Quality mode produces full PBR texture sets — color, roughness, and metalness maps — at 4K resolution in about 2 minutes, versus Fast's 1K color-only textures in about 30 seconds.
**What research it translates (≤3 sentences):** Roblox does not cite an underlying paper or model architecture for this release; the devforum post describes only the product-facing behavior (PBR map generation, text preservation, multi-part mesh support).
**Practical significance (≤3 sentences):** Roblox states Quality mode "preserves text better and adds detail" compared with Fast mode, and that texture generation "now works on meshes with multiple parts," letting creators generate production-grade PBR materials for 3D assets directly inside Studio instead of only flat color textures. This moves the tool from a quick-preview utility toward an asset pipeline usable for shipped experiences, per Roblox's own framing.
**Engineering details (≤3 sentences):** Output maps are color (albedo), roughness, and metalness; normal maps are explicitly not yet supported. The feature is reached through Studio's Model > Texture menu or the Assistant `/generate_texture` command. Roblox lists re-prompting from Fast to Quality with the same inputs, UV preservation, and persisting image previews as "coming soon," indicating the feature is still evolving.
**Limitation / caveats (≤3 sentences):** Roblox states normal maps are not generated in this release. The feature remains beta/opt-in rather than GA, and the forum post gives no numeric quality benchmarks beyond the timing figures (2 min vs. 30 sec) and resolution figures (4K vs. 1K).
