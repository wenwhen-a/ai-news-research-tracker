## NVIDIA Kimodo motion-generation model in Unreal Engine 5.9's guided animation framework
- **Company:** NVIDIA (research/model), integrated by Epic Games into Unreal Engine 5.9
- **Status:** Public beta/preview · **Released:** 2026-11-19 (available in Unreal Engine 5.9 Preview 2) · **New**
- **Surface:** Engine tool — Unreal Engine 5.9 Preview Sequencer (guided animation framework)
- **Primary source:** https://developer.nvidia.com/blog/whats-new-for-game-developers-ai-animation-and-rtx-tools/
- **Underlying research:** NVIDIA Kimodo tech report, "Kimodo" project page (https://research.nvidia.com/labs/sil/projects/kimodo), NVIDIA Spatial Intelligence Lab — no arXiv preprint found; NVIDIA links a tech-report PDF, GitHub code, and a Hugging Face model/demo instead.
- **Availability:** Accessible only inside Unreal Engine 5.9 Preview (not yet a numbered GA release); GPU-accelerated; no standalone pricing/license stated outside the UE5.9 Preview terms.

**What shipped (≤3 sentences):** NVIDIA states Kimodo is "the first model integrated with" Unreal Engine 5.9 Preview's new guided animation framework, letting animators generate character motion directly inside Sequencer's timeline editor. Animators supply constraints — a text prompt, a spline path, and target poses at specific frames — and the model generates motion satisfying them, pairing GPU-accelerated generation with the familiar timeline workflow.

**What research it translates (≤3 sentences):** Kimodo is a kinematic motion-diffusion model from NVIDIA's Spatial Intelligence Lab, trained on 700 hours of optical motion-capture data and controllable via text prompts plus kinematic constraints (full-body keyframes, sparse joint positions/rotations, 2D waypoints/paths). Per its project page, it uses a motion representation and a two-stage root/body denoiser specifically aimed at reducing artifacts such as floating and foot-skating while scaling past the small public mocap datasets that limit most generative-motion models.

**Practical significance (≤3 sentences):** NVIDIA states this lets animators direct character motion with constraints rather than hand-keying every frame, without leaving Unreal's Sequencer. This is the first public integration of a named NVIDIA research motion model into a shipping game-engine animation tool, rather than a standalone research demo. It remains Preview-only, so no studio can rely on it for shipped production today.

**Engineering details (≤3 sentences):** The research page describes a two-stage denoiser separating root and body motion prediction, built on a kinematic (not physics-based) diffusion formulation. The UE5.9 integration is GPU-accelerated and surfaces inside Sequencer as part of a new "guided animation framework" that Epic designed to host external motion-generation models, of which Kimodo is the first. Code, model weights, and a demo are published separately on GitHub and Hugging Face by NVIDIA.

**Limitation / caveats (≤3 sentences):** Both NVIDIA's blog and Epic's UE5.9 release notes label this a Preview feature (UE5.9 itself is a Preview build, previously logged in product_seen.json as an "experimental UAF AnimGen plugin" without the model being named); it is not production-ready and has no committed GA date. No arXiv paper, peer-reviewed venue, or quantitative benchmark numbers are given — only a tech-report PDF — and no license or pricing terms are stated for Kimodo itself outside the engine preview.
