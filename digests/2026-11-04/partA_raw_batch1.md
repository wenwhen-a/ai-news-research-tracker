## Möbius: A Unified Motion-Language Model Bridging Understanding and Generation
- **arXiv:** 2611.05279 · https://arxiv.org/abs/2611.05279
- **Submitted:** 2026-11-03
- **Authors:** Jiazhi Shu, Chengfeng Zhao, Jinyi Wang, Yubo Zhao, Zhiyang Dou, Ronghui Li, Yu Lu, Xinwei Jiang, Zijiao Zeng, Yuan Liu
- **Qualifying affiliation(s):** Tencent Games Motus — Jinyi Wang (project lead), Ronghui Li, Yu Lu, Xinwei Jiang, Zijiao Zeng (corresponding author), and co-affiliation for Jiazhi Shu and Yubo Zhao (other co-authors are HKUST and MIT)
- **Categories:** cs.CV
- **Open release:** code (GitHub repo linked from the project page, https://github.com/JiazhiShu/mobius-code, but as of verification contains only a README stating "Code availability is currently under internal review" — no code files published yet); no weights or live demo found
- **Shipped counterpart:** none found

**Summary (≤3 sentences):** Möbius is a unified motion-language model that understands, generates, and edits human motion within a single framework, rather than pairing a separate language model (for understanding) with a separate diffusion module (for generation). It performs the diffusion generation process directly inside the same multimodal representation space used for motion understanding, operating on continuous frame-level raw motion without tokenization or a pretrained motion VAE. The authors release two model sizes (0.6B-backbone and 1.7B-backbone) trained on HumanML3D and an internal 1,700-hour motion corpus.

**Purpose (≤3 sentences):** The authors state existing motion models are only partially unified because understanding (via a language model) and generation (via a separate diffusion module) remain architecturally split. Möbius aims to close that gap with one model able to caption, generate text-to-motion, complete motion temporally, and perform instruction-guided editing.

**Breakthrough (≤3 sentences):** The authors report Möbius-0.6B achieves R@1 0.8209 and FID 6.1291 on HumanML3D text-to-motion, versus FID 12.2110 for the strongest same-data baseline (MotionStreamer) and FID 13.5194 for HY-Motion-1B. On motion captioning they report BLEU-4 0.2032 / CIDEr 0.5754 versus MotionGPT3's 0.1605 / 0.4077, and on MotionFix editing an FID of 0.0955 versus MotionLab's 0.1339. They state that scaling to 1.7B parameters and 1,700 hours of data shows the unified approach "is effective and scalable."

**Tools & method (≤3 sentences):** Clean motion, noisy motion, and text tokens interact through shared attention with role-specific parameters inside one multimodal transformer, so diffusion-based generation and language-model-style understanding share the same representation space. Evaluation follows the MotionStreamer MS-272 protocol for generation, the MotionLab protocol for editing (using MotionFix pairs), and the TM2T protocol for captioning; the backbone is built on Qwen3.

**Limitation (≤3 sentences):** The authors state their experiments focus on "controlled single-person motion settings" and name multi-person interaction, finer hand/finger motion, cross-body retargeting, and embodied deployment (e.g., robots) as future work. They also note their temporal-completion results demonstrate extensibility across trained tasks "rather than establishing zero-shot generalization to unseen tasks or distributions."
