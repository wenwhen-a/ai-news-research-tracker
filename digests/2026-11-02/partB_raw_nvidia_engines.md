## Phantom Blade Zero — DLSS 4.5 Ray Reconstruction & Path Tracing
- **Company:** NVIDIA (feature shipped in S-GAME's Phantom Blade Zero)
- **Status:** GA · **Released:** 2026-10-28 · **New**
- **Surface:** Shipped game (Unreal Engine title) on GeForce RTX PCs/laptops and RTX Spark; GeForce Game Ready Driver
- **Primary source:** https://www.nvidia.com/en-us/geforce/news/phantom-blade-zero-path-tracing-dlss-4-5-ray-reconstruction/
- **Underlying research:** no traceable paper (NVIDIA has an internal technical write-up, "Technical Insights into DLSS 4: Multi Frame Generation and Transformer-Based Architectures," but it is not posted on arXiv)
- **Availability:** Free at launch for all owners on Steam/Epic Games Store; no separate paywall for the DLSS features; GeForce RTX and RTX Spark required for the path-tracing/DLSS 4.5 path

**What shipped (≤3 sentences):** NVIDIA states Phantom Blade Zero launched October 28, 2026 on GeForce RTX and RTX Spark with the full DLSS 4.5 feature set, including DLSS 4.5 Ray Reconstruction and Dynamic Multi Frame Generation (up to 6X). Enabling path tracing swaps Unreal Engine's Lumen global illumination for ReSTIR GI and automatically turns on Ray Reconstruction, and path tracing is also required for the game's ray-traced water caustics.
**What research it translates (≤3 sentences):** Ray Reconstruction replaces NVIDIA's hand-tuned denoiser chain with a learned, transformer-based denoising network that infers a cleaner image directly from the raw ray-traced signal; the second-generation transformer (introduced with DLSS 4.5 in late August 2026, already tracked) processes more input data and parameters than the first-generation model at a similar compute budget. No company-published paper or arXiv ID ties this specific model to an academic citation.
**Practical significance (≤3 sentences):** NVIDIA states this is one of the highest-profile day-one AAA integrations of the complete DLSS 4.5 stack (Ray Reconstruction plus 6X frame generation) in a shipped, Unreal Engine-based action game rather than a tech demo. NVIDIA reports up to 450 fps on a GeForce RTX 5090 at max settings with path tracing enabled, letting players run full path tracing with real-time frame rates on current RTX hardware.
**Engineering details (≤3 sentences):** The integration is engine-level: path tracing substitutes Unreal Engine's Lumen GI with NVIDIA's ReSTIR GI implementation rather than running alongside it. Ray-traced water caustics are gated specifically behind path tracing being enabled, and the game ships alongside a dedicated GeForce Game Ready Driver for day-one support.
**Limitation / caveats (≤3 sentences):** This is a shipped-game feature integration, not a new DLSS version; the underlying DLSS 4.5 Ray Reconstruction model itself was already tracked (first_seen 2026-09-13) and is unchanged here. GeForce NOW cloud support for this specific title was not confirmed in NVIDIA's own post. Performance figures (450 fps claim) are NVIDIA's own, with a differing third-party chart (383 fps RTX 5090 at 4K) that likely reflects different test settings.
