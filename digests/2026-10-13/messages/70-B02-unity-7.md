**[B02 · Update] Unity 7**
- **Company:** Unity
- **Status:** Public beta/preview · **Released:** 2026-10-05 · **Update**
- **Surface:** Engine / editor (downloadable public alpha)
- **Primary source:** <https://unity.com/blog/unite-seoul-keynote-2026-recap>
- **Underlying research:** no traceable paper
- **Availability:** Public Alpha (build 7000.0.0a7) downloadable today from Unity's official Alpha release page (unity.com/releases/editor/alpha), no invitation required; Unity ships "two alphas per week" during this phase. No stated price change from existing Unity plans; full 7.0 release date not yet given.

**What shipped:** Update since 2026-09-28: Unity 7, previously Announced-only (previewed at Unite Seoul with no usable build), now has a public, self-serve Alpha build (7000.0.0a7) that anyone can download from Unity's official alpha channel — moving it to Public beta/preview tier.
**What research it translates:** Unity 7's core change is a CoreCLR/.NET-modernized scripting runtime and new 2D/3D graphics tooling, as previously announced; this is an engine architecture overhaul rather than a published research result, so no traceable paper applies.
**Practical significance:** Developers can now install and test Unity 7 directly rather than waiting on a roadmap promise, letting studios begin evaluating the new .NET/CoreCLR runtime and graphics changes ahead of a stable release.
**Engineering details:** A Unity staff reply in the alpha thread states domain reloads have been replaced by code reloads and assembly-load-context (ALC) reloading, and that Player/Editor Compatibility Levels remain on .NET Standard during this alpha window (full .NET compatibility is not expected to land before the alpha period ends).
**Limitation / caveats:** This is an early, explicitly unstable Alpha, not a beta or release candidate, and Unity gives no committed date for Unity 7's full/GA release.
