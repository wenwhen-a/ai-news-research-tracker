## Studio MCP Server — Open Cloud Access & Asset Import (Roblox)
- **Company:** Roblox
- **Status:** GA · **Released:** 2026-11-04 · **New**
- **Surface:** Studio dev tool / AI agent integration (external MCP clients, e.g. Claude Code)
- **Primary source:** https://devforum.roblox.com/t/studio-mcp-server-updates-open-cloud-access-in-your-mcp-client-and-asset-import-workflows/4975849
- **Underlying research:** no traceable paper
- **Availability:** Works with external MCP (Model Context Protocol) clients such as Claude Code; Roblox states it does not apply to Studio's own built-in Assistant. Free platform feature; permissions are configured per game and saved per account, with collaborators setting their own.

**What shipped (≤3 sentences):** Roblox expanded its Studio MCP server, which lets external AI-agent clients connect to Roblox Studio, with a new `open_cloud_invoke` tool that calls Open Cloud APIs (creating developer products/game passes, changing game/place settings, publishing, restarting servers, reading analytics, calling allowlisted external APIs) and a new asset-import workflow that lets an agent bring in a Blender/Maya model (GLB/FBX) and correct its scale, rotation, textures, colors, anchoring and placement. Roblox also shipped a granular per-game permission system covering Open Cloud scopes, upload folders, DataStore/MemoryStore access from Luau, and allowed internet domains, plus three new "Skills" (rbx-open-cloud-usage, rbx-permissions, rbx-import-asset), an in-Studio MCP status indicator, and background playtests.
**What research it translates (≤3 sentences):** This is an engineering/product update to Roblox's own AI-agent tooling, not a published research result; Roblox does not cite an underlying paper.
**Practical significance (≤3 sentences):** A Roblox developer can now let an AI coding agent (Roblox's example: Claude Code) not just edit code in Studio but also call Roblox's Open Cloud platform APIs and import ready-made 3D assets from external tools, within permissions the developer explicitly grants per game. Roblox states this is an expansion of the MCP server "beyond creation" into operations and asset pipelines.
**Engineering details (≤3 sentences):** Ships as an update to the existing external-MCP-client integration (distinct from Studio's built-in Assistant); permissions are scoped and stored per account/game, and the asset-import path explicitly supports GLB/FBX files exported from Blender or Maya. Roblox also fixed a bug where the MCP server setting could silently turn itself off, and added connection-reliability fixes and a per-place Studio ID.
**Limitation / caveats (≤3 sentences):** Per Roblox: Open Cloud access through this tool cannot delete or archive models/images (must be done via the Creator Dashboard); some endpoints require an API key the MCP token can't supply, so the agent falls back to a Studio tool or points the developer to the dashboard; DataStore writes still require "Enable Studio Access to API Services" separately, agents cannot grant themselves permissions, and uploaded assets are permanent, go through moderation, and are attributed to the game/group owner.
